# BoxKeep · 家庭收纳盒内容整理

纯前端、可离线使用的家庭收纳盒整理页。用于搬家、换季整理或储物间收纳时，快速记录每个收纳盒里有什么、放在哪里、优先找哪个。**不接入任何后端**，数据保存在浏览器 IndexedDB，并支持导出 / 导入 JSON。

## 功能

- **收纳盒字段**：编号、所在房间、内容摘要、重量等级、易碎提醒、查找优先级、摆放顺序、确认状态、备注。
- **筛选**：按关键词、房间、重量、优先级、确认状态、是否易碎多维筛选。
- **排序**：按摆放顺序 / 优先级 / 重量 / 房间 / 编号 / 确认状态排序。
- **拖拽排序**：在「摆放顺序」排序且无筛选时，可拖拽卡片调整摆放顺序并自动重编号。
- **复制相似盒子**：一键复制现有盒子作为新盒子的模板。
- **批量操作**：多选后批量标记「待整理 / 已确认 / 需加固 / 暂缓处理」或批量删除。
- **自动异常检测**：编号重复、同房间盒子过多、易碎却缺少提醒、摆放顺序重复、高优先级项过多，可一键定位涉及的盒子。
- **常用物品清单视图**：仅展示需优先查找 / 需加固 / 备注不完整的盒子，并按房间汇总数量。
- **本地恢复与导出**：数据自动保存在 IndexedDB，刷新后自动恢复；支持导出 JSON 备份和导入还原。

## 技术栈

React 18 + TypeScript + Vite，除 React 外零运行时依赖；原生 IndexedDB 存储，原生 HTML5 拖拽 API。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 生产构建，输出 dist/
npm run preview  # 预览构建产物
```

构建产物为纯静态文件，可直接部署到任意静态托管，或双击 `dist/index.html` 离线打开。
